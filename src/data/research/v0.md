## Summary

v0 (v0.app, formerly v0.dev) is Vercel's AI product for generating working web apps, components, and websites from natural-language prompts. Originally launched in late 2023 as a React/Tailwind component generator, by April 2026 it has evolved into an "agentic by default" full-stack app builder: it plans, creates tasks, connects to databases, generates entire Next.js projects, provides visual design mode with live preview, GitHub sync, and one-click deploy to Vercel. It now also offers an iOS app and its own family of models (v0 Mini, Pro, Max, Max Fast). Positioning is consumer-friendly — designers, PMs, and indie builders can ship production-looking UIs and apps without writing code — while still producing real Next.js/Tailwind code developers can own and extend.

## Classification

- **Type:** `agent-tool` — v0 now plans multi-step work (not just one-shot code generation), connects to external services (databases, GitHub), and delivers runnable artifacts. It clearly crosses from "generator" to "agent."
- **Subtype:** `agentic-app` — the consumer surface (v0.app) is a chat-first product; the agent plans and acts on the user's behalf (spins up project scaffolds, wires databases, deploys) inside a hosted environment. Matches the pattern used by ChatGPT Agent and Claude Computer Use entries.
- **Category:** Team/Organization-Backed (Vercel; commercial, closed-source app + closed models).
- **Difficulty:** `beginner` — explicitly aimed at "anyone can build a web app." Natural-language entry point, visual editing, templates, free tier.
- **Ladder rung:** **2 — Agentic App.** Rationale below.
- **Audience:** `Curious builder` — primarily non-developers, designers, and indie makers who want to ship UIs and small apps without a dev env; developers also use it, but the graduation path from v0 is to developer harnesses (Cursor, Claude Code).
- **Use Cases:** `Dev` (scaffolding web projects, UI components), `Content` (landing pages, marketing sites).
- **Features:** none of the directory's standard flags apply cleanly — v0 is closed-source, cloud-hosted, and not model-agnostic (runs on Vercel's in-house v0-* models). Leave `features: []`.
- **Tag:** `agentic-app`

### Ladder rung rationale (2 vs 3)

v0 belongs at rung 2 (Agentic App), not rung 3 (Agent Tool), in 2026 for three reasons:

1. **Consumer UX.** v0.app is a chat product with templates, visual editing, and an iOS app — indie makers and designers are the primary audience, not developers running a local agent harness.
2. **The agent does the work, not the user.** v0 plans the project, creates tasks, wires the database, and deploys. The user types goals; v0 ships artifacts. Rung 3 (Agent Tool) implies the user is operating the agent inside a dev workflow — that's the Cursor / Claude Code pattern.
3. **v0 does not edit your local repo.** It generates projects in its hosted environment and syncs to GitHub — it is not a coding agent that takes over your filesystem. That's exactly the rung-2 boundary the directory already draws (see ChatGPT Agent's `not_for`: "Editing files in your local repo").

Developers who want local-repo agency graduate upward to Cursor, Claude Code, or Windsurf — which is how the community itself frames it (multiple X posts position v0 as the "design / scaffold" step and Cursor/Claude Code as the "dev" step).

## Community Sentiment (from X/Twitter)

- **How people describe it:** "high-end React UI with real-time visual editing" (Anand Butani, Apr 2026); the "Design" step in the 2026 startup stack ("Ideation → Claude, Design → v0, Dev → Cursor, Launch → Vercel" — @startupsavage).
- **Common use cases mentioned:** scaffolding UIs, landing pages, SaaS dashboards; prototyping before handing off to a dev harness; designers shipping work without a front-end engineer. One developer hacked Xcode support into v0 to build a Swift app in 7 minutes (@Baconbrix).
- **What people like:** speed, polish, natural Next.js/Tailwind output, free tier is usable, iOS app, GitHub sync.
- **Criticisms / limitations:** Recurring thread from multiple devs: AI-built Next.js apps (v0, Bolt, Lovable) often miss production concerns — auth middleware gaps, API data exposure, N+1 queries, exposed env secrets, no error boundaries (@Webb3Fitty). Not great for complex back-ends or cross-cutting concerns. Credits run out quickly on larger projects. Some users say Readdy or other tools produce more polished marketing pages out of the box (@nian_pan61042).
- **Compared to:** Lovable (idea-to-SaaS with Stripe + GitHub), Bolt.new (browser-based no-setup), Replit Agent (auto-handles DB + hosting), Firebase Studio, Caffeine AI. The "Tier 1: Idea-to-App" bucket in community framings consistently groups v0 with Lovable and Bolt.

## Similar Tools in Directory

- **ChatGPT Agent** (`agent-tool` / `agentic-app`, rung 2) — closest structural match: consumer agentic surface backed by a frontier model lab, with hosted environment the agent acts in. v0 differs in that it's narrow (web apps) not general, and produces code artifacts you own.
- **Claude Computer Use** (`agent-tool` / `agentic-app`, rung 2) — same rung, same "agent takes action" framing. Computer Use drives the user's machine; v0 works inside a hosted sandbox and ships deployed URLs.
- **Skills CLI** (`developer-utility`, Vercel) — same creator, very different position in the ladder. Skills is a package manager for agent instructions used by developer harnesses; v0 is the consumer product.

No existing entry for Lovable, Bolt, Replit Agent, Cursor, or Windsurf was found in `directory.json` at the time of research — these are referenced in `graduate_to` / `alternative_to` but may not yet exist as entries. Worth confirming before publishing.
